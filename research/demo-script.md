# Lynkr demo script (about 3 minutes)

Runs in demo mode (no AI key). Say so at the start: drafts are templates built from your answers; with a key, the same flow uses real AI.
Before you start: `npm run dev`, open http://localhost:3000 in Chrome, and click "Start over" if old data shows.

## Test profile (fictional, not a real person)
- **Goal:** A full-time job · **Target role:** Data analyst
- **Background:** Final-year B.Com at a tier-3 college in Pune, self-taught SQL, no internship yet

  6. Analytics firms in Pune, such as Fractal.

## If something goes wrong
- A tab is empty: click "Answer more questions and rewrite" to regenerate drafts.
- Old data appears: "Start over" in the footer.
- The round "N" badge bottom-left is Next.js's dev indicator; it isn't part of the app.
